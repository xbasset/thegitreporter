Unsloth can refuse a disruptive model load instead of replacing a resident

What changed. Supported GPU paths compare free memory with estimated weights and generation headroom. Fit may free models; Always refuses displacement. A media swap can separately save the primary GGUF chat cache before unloading.

Why it matters. Operators serving local agents alongside media work gain an explicit choice about which workload may displace another. Co-residency is conditional, and refusing a request can preserve the current service.
