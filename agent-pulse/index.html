Audit / Project-specific claim
action

Separate Gemini CLI access from Google's new recommendation

What changed. The new banner concerns model optimization. The accompanying documentation cleanup does not remove executable features or establish that enterprise and paid API model access is denied.

Why it matters. Operators keeping Gemini CLI for existing automation and inspectable code now have an explicit product recommendation to evaluate against their own task requirements.
