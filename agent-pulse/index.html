Test whether resume replays work or starts it again

Qwen Code now refuses a stored workflow resume when its journal is missing and makes eligible interrupted runs visible on a later interactive or ACP start.

Today's Action

Test / Project-specific claim
action

Test whether resume replays work or starts it again

What changed. The journal loader distinguishes absence from an empty replay. A separate checkpoint records a registered attempt, and a later eligible process can turn it into failed history with an interruption explanation. Resumption remains explicit.

Why it matters. A supervisor needs to distinguish saved results that can be replayed from agent calls that would execute again under a familiar run identifier.

Claim coverage / complete 29 / 29

All 29 included projects and all 13 core coding agents have fresh source receipts for this edition.

Builders evaluating Qwen Code workflows 20–30 minutes with an existing test installation

Exercise a disposable two-step restart

On a build containing both changes, interrupt a harmless two-step workflow after the first recorded result. Restart interactively and inspect interrupted history, then explicitly resume and count live steps. In a separate disposable case remove the journal and confirm refusal. Keep external side effects out of this test.

Receipt 1 / QwenLM/qwen-code / commit / Sep 18, 05:19 AM GMT+2 Refuse missing-journal resume

The loader distinguishes missing and unreadable journals; the runner refuses them before dispatch with storage configured.

 Receipt 2 / QwenLM/qwen-code / commit / Sep 18, 02:00 AM GMT+2 Discover interrupted workflow runs

Confidence / strong

The merged runner, journal and checkpoint implementation agree with the added regression cases and public PR descriptions.

Limit

No live process-kill reproduction or released-package mapping was performed. Best-effort persistence, legacy empty journals and headless discovery limits prevent a blanket recovery guarantee.

What would change this

Revise the call if the installed implementation accepts a missing stored journal and dispatches agents, or a later patch changes the explicit-resume and ownership rules.
