Today's Action

Audit / Project-specific claim
action

A new model route should trigger a permission-mode audit

What changed. The inspected commit updates Goose's canonical model data, Anthropic request formatting, and focused tests for the Claude 5 adaptive-thinking shape. Separately, Goose documents Autonomous, Manual Approval, Smart Approval, and Chat Only modes; its public permission inspector has distinct paths for explicit policy, read-only classification, extension management, and unknown tools.

Why it matters. A model compatibility update can change the intelligence at the center of an agent without changing the tools around it. If that agent can use MCP extensions and local developer tools, the useful safety question is whether the operator can still explain which actions need confirmation, rather than whether the new model name appears in a picker.

Claim coverage / complete 24 / 24

All 24 included projects and all 13 core coding agents have fresh source receipts for this edition.

Goose operator 20–30 minutes

Audit one model-to-tool path

In a non-sensitive workspace, select the intended Goose permission mode, enable only one known extension, and run a bounded task with the newly mapped model. Record which tool calls proceed, which ask for approval, and how an unfamiliar tool is handled before granting the model broader access.

Reversible
Agent-platform builder 45–60 minutes per integration

Keep compatibility and authority tests separate

When adding a provider or model family, test the request-format contract independently from permission behavior. Exercise explicit allow, deny, unknown-tool, extension-management, and read-only paths so a passing provider test cannot stand in for an authority audit.

Reversible

Limit

This is source-level Goose evidence. It does not establish a release, a working provider account, the behavior of every extension, or the correctness of all permission classifications in a deployed session.

What would change this

Revise this call if the provider mapping is reverted, if a public release changes the documented default or mode semantics, or if later source or tests show that a supported extension path bypasses the stated permission controls.

Watch next. Watch for a Goose release and a public end-to-end test that pairs a newly mapped provider with a local extension under each permission mode, including an unknown-tool and denied-action path.
