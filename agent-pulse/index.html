Pydantic can append changing state without rewriting its earlier instructions

What changed. The framework records instruction identities and a trusted baseline, then appends typed replacements or withdrawals. Provider delivery can be a system message or system-tagged user text; prefix stability does not establish equal instruction authority.

Why it matters. Teams can test changing state separately from stable prompt material without maintaining all of the history bookkeeping themselves. Correct state-following and useful cache reuse still need to be measured together.
