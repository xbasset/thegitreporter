action

Test whether recalled plans lead back to the user’s actual decision

What changed. The October 1 change adds an observations recall mode, cursors across retained generations and guidance to confirm disputed details against original messages. Paging filters out reflection summaries; it does not recreate missing history.

Why it matters. An assistant’s proposed date and a user’s accepted date are different facts. A navigable source trail gives the agent a way to distinguish them.

Claim coverage / complete 29 / 29

All 29 included projects and all 13 core coding agents have fresh source receipts for this edition.

Builders evaluating Mastra observational memory One isolated memory-retrieval test

Try a proposal-and-rejection fixture

In a disposable application pinned to a revision containing this change, create a conversation in which an assistant proposes a date and the user rejects it. After observation and reflection, ask which date was agreed. Inspect whether recall pages the relevant observations and reads the original messages. Keep production memory unchanged.
