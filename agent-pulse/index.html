watch

Pi v1.4.0 adds image inputs to more classifier routes

What changed. Image transport differs: TypeSafe uses assets and an experimental header, Clef uses data URLs, and OpenRouter uses image_url content. Model capability declarations and integration version ranges are separate requirements.

Why it matters. A released image route creates a testable option, but teams must check the complete stack before relying on it to classify screenshots or other visual inputs.
