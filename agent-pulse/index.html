Today's Action

watch

Check Goose recipes that expect a background task handle

What changed. The October 7 Summon change removes async task handles and later collection through load, including its peek and cancel arguments. October 5 foreground machinery runs pending children concurrently and delivers their outcomes through the parent session; the legacy loop returns results directly.

Why it matters. A recipe can retain an old async argument without preserving its detached behavior. Authors need to check result delivery and the next step, not only whether the call parses.

Claim coverage / complete 29 / 29

All 29 included projects and all 13 core coding agents have fresh source receipts for this edition.

Authors maintaining Goose recipes or integrations One recipe review and a bounded test when a containing version is available

Review detached-work assumptions before upgrading

In a disposable copy, identify instructions using async delegation and later task-ID collection. Compare them with the revised upstream batch example, then test completion and interruption against a version containing the change before updating the real workflow.
