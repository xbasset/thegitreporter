watch

Watch for a released diffusion trainer with a checked task result

What changed. DiffusionTrainer delegates the training objective to a family profile. The Gemma profile supplies its corrupted canvas through decoder_input_ids and selects the last contiguous supervised response span; the shared input format does not make every family's supervision equivalent.

Why it matters. Researchers can assemble experiments with less separate integration work, while checking that the intended answer actually reaches the learning objective. Existing diffusion fine-tuning routes predate this change.

When a released package contains the October 10 trainer, pin the package, model and dataset. Inspect which response tokens each profile supervises, then run a small disposable held-out task comparison against the unmodified model. Record memory and training cost as well as answer quality.
