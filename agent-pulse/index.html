Test / Project-specific claim
action

Check the boundary behind a successful Studio tool call

What changed. The planner records requested and effective modes separately. The tool wrapper preserves refusal for unsafe working folders and construction failures, while recording a separate path for user-approved host access.

Why it matters. A completed Python or Terminal command does not establish which filesystem boundary protected the host. Operators need the execution record and a test of their actual configuration.

Compare harmless canaries with the execution record

In a disposable environment, identify the pinned build and execution mode. Compare an allowed working-folder operation with an outside read of a harmless canary that the host can read. Inspect effective mode, OS-isolation flag and limitations. Do not use real credentials or weaken host policy to force a pass.
