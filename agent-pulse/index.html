watch

Give screenshot judgments a separate test in Pi

What changed. Codemode forwards an image block and JSON task state through models.classify. The OpenAI adapter serializes the image with the state and returns a Boolean probability, choice or score; a refused answer produces an error result rather than automatic fallback.

Why it matters. Builders can isolate recurring screenshot questions from the main chat and compare that path with their current review method. The callable interface makes the comparison possible; its accuracy still needs measurement.

Claim coverage / complete 29 / 29

All 29 included projects and all 13 core coding agents have fresh source receipts for this edition.

Builders already using Pi scripts for interface review One small test-set preparation and optional API trial

Prepare a small labeled screenshot comparison

Use non-sensitive screenshots with known defects and unchanged question criteria. Compare classifier and chat outputs for missed defects and false alarms before giving either authority to approve a change. Record latency and all billed work when you choose to run the experiment.

Limit

No live API call, package execution or visual-accuracy test was performed. OpenAI API-key access is required; a ChatGPT OAuth sign-in does not make this classifier available in Pi. Returned probabilities are not calibration evidence.

What would change this

A reproducible containing-release test showing images are dropped or the typed result cannot reach codemode would overturn the interface finding; a labeled evaluation showing no useful accuracy/cost tradeoff would weaken the proposed use.
