Try old recipes before embedding the lean Goose build

Goose's merged lean ACP executable gives application teams a smaller build target, but existing recipe declarations can request extensions that target omits.

One decision-worthy insight. Action, effort, and rollback. 29 / 29 included projects monitored. Methodology ›

Today's Action

Test / Project-specific claim
action

Try old recipes before embedding the lean Goose build

What changed. The lean build disables tree-sitter and its analyze registration. The recipe parser still injects analyze for an older built-in developer declaration; a public review traces the resulting extension-load failure, which the author accepts.

Why it matters. A successful package-size check does not prove that imported agent configurations will load. Embedders need an explicit compatibility policy for the feature set they ship.

Claim coverage / complete 29 / 29

All 29 included projects and all 13 core coding agents have fresh source receipts for this edition.

Application teams evaluating Goose's lean ACP binary One focused integration session after building both configurations

Check representative recipes against the pinned feature set

In an isolated integration environment, pin the Goose revision and build features, then try representative existing recipes, including a legacy built-in developer declaration. Record which extensions load and which are explicitly rejected. Compare with the normal build before changing any bundled runtime.

 Receipt 2 / aaif-goose/goose / pull-request / September 22, 2026 Legacy recipe compatibility review

Traces automatic analyze injection to a missing-extension failure in the lean configuration.

Confidence / developing

The recipe parser and conditional extension registry agree with the specific public review; the author explicitly accepts this compatibility boundary.

Limit

We did not compile the binary, independently reproduce the recipe failure, measure its size or verify a released lean artifact. The ordinary full build is a different configuration.

What would change this

Revise the recipe warning if the shipped lean configuration includes analyze or its recipe-loading path demonstrably handles legacy developer declarations without requesting an unavailable extension.

Watch next. A pinned distributable lean artifact and migration tests that show how old recipes and agent settings are handled.
